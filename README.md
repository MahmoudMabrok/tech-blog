# نشرة التكنولوجيا

بلوج بسيط باستخدام Jekyll على GitHub Pages.

المحتوى يقرأ من ملف `_data/articles.json`.

لنشر الموقع:
1. اذهب إلى Settings > Pages
2. اختر Source: Deploy from a branch
3. Branch: main, Folder: / (root)
4. Save

الموقع متاح على: https://mo3ta.top/tech-blog

الدومين `mo3ta.top` جاي من موقع المستخدم، ومش من المستودع ده. متعملش ملف CNAME هنا.
